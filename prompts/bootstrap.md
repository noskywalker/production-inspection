## Plan: Bootstrap K8s Production Inspection Agent Docs

Create a documentation-first scaffold for a single production inspection agent that operates through a Kubernetes MCP server, 
constrained by explicit harness rules and modular skills. 
The plan sets clear governance (`can`/`cannot`), standardized inspection workflows, 
and reusable skill specs so future implementation stays safe, auditable,
and consistent with SRE/security best practices. Please overwrite any existing directory structure and files with the following scaffold.

### Please follow these steps to initialize the inspection scaffold documentation:

Define docs structure and naming in [README.md](../README.md), [AGENTS.md](../AGENTS.md), [agents/inspection.agent.md](agents/agent.md), and [skills/](skills/).Below infor should be included in the AGENTS.md file:

- The purpose of the file is to provide a comprehensive overview of the production environment inspection harness, including its scope, objectives, and governance rules.
- Initialize the inspection objectives, allowed actions, forbidden actions, approval gates, and audit requirements.

- Create [agents/agent.md](agents/agent.md) describing single-agent lifecycle, MCP interaction model, and `skill_invocation_policy`.
- Draft [AGENTS.md](../AGENTS.md) with production-environment overview, scope boundaries, and `inspection_objectives`.
